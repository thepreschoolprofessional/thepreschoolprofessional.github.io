Classroom QR Cards

Print, cut apart and post one card by each classroom door. Same QR codes every time; they never need reprinting.

How to set up each classroom

  1. Print this page (Print button above). One card per room, plus a tablet card for each school.
  2. Cut the cards apart and post each room's card at the classroom door at adult eye level (laminate it if you can).
  3. Anyone scans with the phone camera and the room page opens right away: cleaning chart, bathroom chart, indoor inspection, daily schedule and teacher bios.
  4. Classroom tablet: scan the tablet card (or open the Bear Line Classroom Pack link), pick the room, then Add to Home Screen (iPad) or Install app (Android). It opens straight to that room every time.

What each room page shows

The last 2 months of cleaning charts and inspections (green = done, red = needs attention). If today's chart is not done yet, a red note and a Sign in button ask the teacher to complete it right now. The daily schedule highlights what should be happening right now, and the page updates by itself when a director edits the schedule.
